# startup-website2
**Description**: This project is a web page designed using React featuring a responsive layout and modern design elements which include mobile  and desktop view. Components and Hooks were used,the input fields on the Contact Us page are being tracked using the useState hook.The website was designed with animation using Framer motion.A custom map was incorporated that displays office address as the location marker

## Overview
This project is built using React.It provides a visually appealing,responsive layout, interactive for a web page. It includes sections such as:
- A header with navigation.
- A Herosection.js with headings.
- A "Service.js" section with descriptions.
- A "Contact.js" incorporated with Map.
- A "Footer.js" with additional links and information.

## Features
- **Responsive Design**: The layout adjusts to various screen sizes using media queries.
- **Custom properties**: Utilizes CSS variables for theme colors, making it easy to adjust the overall color scheme.
- **Modular Components**: Reusable and customizable components to easily adjust content.
- **Dynamic Navigation**: Smooth page transitions powered by React Router.
- Users would be able to press the hamburger menu to display the main_mobile_menu.

## Setup Instructions

1. **Clone the Repository**:
```sh
git clone https://github.com/musyelevateher/startup-website2.git
```
2. **Navigate to the project Directory**:
```sh
cd startup-website2
```
3. **Start the developer server**:
npm start
